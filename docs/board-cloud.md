## 复现

在本机或已授权的华为开发者空间，进入仓库目录。接收服务仅监听回环地址。

```sh
python board_receipts.py --port 8091
```

另开终端，运行以下命令。样例为虚构数据。

```sh
python board_receipts.py --port 8091 --verify-upload samples/board-capture.json
```

检查输出中的事件数、回执、接收时间、回读一致性和去重结果。使用华为开发者空间登录态预览查阅记录。网页病例服务可按 README 独立启动，在云端通过已授权的 HTTPS 预览提供访问。

实机验证采用训练后的串口摘录导入。板子语音回复由原来的语音后台生成。实时转发和华为云生成回复后由板子播出尚未实测。护理教师对照的耗时、误标和漏标仍待实际参加后记录。

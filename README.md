# 星络智检-圣医智教

小圣老师是一套护理沟通模拟训练原型。学员用普通话与模拟患者对话，教师可核对双方原句、修正候选沟通项目并导出复盘。网页训练包含鼻导管吸氧和鼻饲。实体板另完成了一轮小儿静脉输液模拟，相关实机事件已导入华为云。

## 运行网页

使用 Python 3.13，无第三方 Python 依赖。

```sh
python app.py
```

打开 http://127.0.0.1:8080/ 。选择病例、开始训练，输入“请问您的姓名和住院号”。病例使用虚构数据。支持 Web Speech API 的浏览器也可用麦克风和普通话播报。结束后可逐条标注并下载 JSON。教师标注随导出文件保存。

## 验证与部署

- `python verify_training.py` 验证两个病例的规则边界。
- `python verify_http.py` 用临时数据库验证 HTTP 交互、重试、隔离及复盘持久化。
- `python verify_paraphrases.py regression.csv` 回放 18 条样稿外修订用例。加 `--holdout` 运行 8 条留出用例，当前有 3 条已知失败。
- [板端记录接收与实测结果](docs/board-cloud.md) 包含华为开发者空间部署和接收验证步骤。

截至 2026-11-24，华为开发者空间已验证网页登录态训练、教师标注和导出，也已接收一轮实体板训练的 5 条经过筛选的串口事件。未登录请求访问接收回执返回 401。公开示例使用新编的虚构文本，实际回执和原始串口日志留在队内。

## 实机训练复盘

启动网页服务前，将 `BOARD_RECEIPT_DB` 指向板端接收服务已经生成的 SQLite 数据库。在华为开发者空间中，两个服务应使用同一工作环境，复盘服务用独立端口，数据库通过只读连接查询。

```sh
BOARD_RECEIPT_DB=/root/workspace/xiaosheng-training/board-receipts/board_receipts.sqlite3 HOST=127.0.0.1 PORT=8092 python3 app.py
```

通过已登录且受访问控制的预览入口打开网页，在「实机训练复盘」输入接收服务返回的完整回执编号。对照病例、来源、入库时间及双方原句，确认候选沟通证据能跳转到对应学员发言。未找到证据的项目留给教师核对。JSON 导出用于留存本次复盘。实际回执和导出仅在队内流转。

运行 `python verify_board_review.py`，用临时数据库检查回执查询、角色区分、明显否定句、404 和无效编号。
